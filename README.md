# Ширма

Одна локальная страница. Мастер после пароля собирает сцены в редакторе. Кнопка Share открывает чистое окно этого кадра: его забирает OBS и стримит на планшет.

Редактор — [GrapesJS](https://grapesjs.com/) (BSD-3-Clause). Архивы собирает [JSZip](https://stuk.github.io/jszip/) (MIT). Оба лежат в `vendor/`, сеть для работы не нужна.

Кадр по умолчанию **1368×786**. Размер меняется в верхней панели.

Всё хранится в IndexedDB этого браузера. JSON и ZIP забирают страницы с картинками и не забирают пароль. Пароль только не пускает в редактор на этом компьютере.

## Как открыть

Из этой папки:

```
python -m http.server 8080
```

Дальше в браузере: `http://127.0.0.1:8080`

Мастер задаёт пароль при первом входе. Share открывает второе окно. Для OBS надёжнее источник «Браузер» со ссылкой `http://127.0.0.1:8080/index.html?view=play` и размером 1368×786.
