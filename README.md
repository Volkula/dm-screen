# Ширма

Модуль Foundry VTT 13. Планшет в ширме заходит отдельным игроком и видит только стол.

## Установка в Foundry

В списке модулей: **Install Module** → вставь адрес манифеста:

```
https://github.com/Volkula/dm-screen/releases/latest/download/module.json
```

Обновления Foundry подхватывает с того же адреса.

Создай игрока с именем **Ширма** (роль Player). На планшете зайди в мир под ним. Если имя другое, укажи его в настройках модуля.

## За столом

На панели жетонов у мастера две кнопки:

- **Показать кадр на ширме** — планшет переходит на текущую сцену и тот масштаб, который сейчас у мастера.
- **Затемнить ширму** — планшет гаснет в чёрный, стол на месте.
